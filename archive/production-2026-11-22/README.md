# florra.net as it was live on Nov 22 2026

A byte-for-byte copy of every page and text asset served by the production
deployment before the site was cut down to management only (Vercel
dpl_3EA8PraxfD4aw7WYyTVM56rp8Tot, built from commit e077c50 on a branch that
no longer exists). Images, audio and three.js are the same files as in
`assets/` on branch `archive/full-site-2026-11-22`, which holds the full
collection source (WORLDS, scripts/build.mjs, every project page).

To bring a world back: copy its page from here, or rebuild the collection with
`npm run build:collection` on the archive branch.
